# VOKE - AI-Powered Interview Practice

VOKE is an AI-powered interview practice application designed to help you master your next interview. Practice with an intelligent AI interviewer, get real-time feedback, and ace your dream job interview. All in your browser, and completely private.

## ✨ Features

- **Brain AI-Powered Interview**: Practice with our intelligent AI interviewer that adapts to your responses and provides realistic follow-up questions.
- **Mic Voice & Text Input**: Answer questions using voice (speech-to-text) or type your responses. Practice the way you prefer.
- **Video Record & Review**: Record your interview sessions with webcam and audio to review your performance and body language.
- **TrendingUp Instant Feedback**: Get detailed feedback on your answers, including strengths, areas for improvement, and scoring.
- **Shield 100% Private**: All your interview data is stored locally in your browser. No data leaves your device.
- **Target Role-Specific Questions**: Practice with curated questions for Frontend, Backend, Data Science, and more roles.

## 🛠️ Tech Stack

- **React 19** - UI Library
- **Vite** - Build Tool
- **React Router** - Routing
- **Tailwind CSS** - Styling
- **GSAP** - Animations
- **Radix UI** - Accessible UI Components
- **Lucide React** - Icons

## 🚀 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository
2. Install dependencies using yarn (recommended) or npm:

```bash
yarn install
# or
npm install
```

### Development

To start the development server, run:

```bash
yarn dev
# or
npm run dev
```

The application will be available at `http://localhost:5173` (or the port specified by Vite).

### Build

To build the application for production, run:

```bash
yarn build
# or
npm run build
```

The built files will be located in the `dist` folder.

### Linting

To run the linter, run:

```bash
yarn lint
# or
npm run lint
```
